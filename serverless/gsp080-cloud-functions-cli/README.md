# GSP080: Cloud Run Functions Qwik Start - Command Line

## Architecture Overview
This directory contains a Node.js serverless function triggered by Google Cloud Pub/Sub events.

- **Compute:** Cloud Run Functions (Gen 2)
- **Runtime:** Node.js 20
- **Trigger:** Pub/Sub topic (`cf-demo`)
- **Event Handling:** `@google-cloud/functions-framework`
