# GSP095: Pub/Sub: Qwik Start - Command Line

## Overview
This directory contains the automation steps for managing Google Cloud Pub/Sub resources using the `gcloud` CLI.

## Architecture
- **Service:** Google Cloud Pub/Sub
- **Components:** 
  - Topic: `myTopic`
  - Subscription: `mySubscription` (Pull subscription)
- **Operations:** Message publishing, auto-ack pulling, and limit-based batch pulling.
